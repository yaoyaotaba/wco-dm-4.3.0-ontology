从 WCO 官方发布包中的 LIB（元素库）与 OIS（总体信息结构）工作簿构建，提供 OWL 2 DL 本体、SKOS 代码表、SHACL 形状与可交互浏览页面。

数据来源与构建方法

源文件来自 WCO 数据模型应用发布的 4.3.0 包页面。发布包通过公开接口 GET /datamodel/infopage/4.3.0 提供文件树，实际文件位于 /webpage/4.3.0/…。

  • LIB：270 个类的定义、835 个数据元素、格式、核心数据类型、代码表目录与 UN/CEFACT 超类对齐信息。
  • OIS：1,993 个类出现位置与 7,810 个属性出现位置，用于恢复类之间的包含角色与上下文。
  • 对两者取并集：补入仅出现在 LIB 的 42A Declaration、58C AIP、74B LPCO 与 599 Net weight；这三类作为根单据挂在 OIS 下，并显式标注为推断放置。

完整来源清单、校验和与下载状态见 download-manifest.csv。

标准与序列化

  • OWL 2 DL：274 个类（含 OIS 根）、273 个对象属性、836 个数据类型属性；全部类均为 wco:DataModelComponent 的子类。
  • RDF 1.1 Turtle 为规范序列化；同时提供 RDF/XML 与 JSON-LD 1.1，三者均为 26,663 个三元组。
  • SKOS：135 个 skos:ConceptScheme，69 个代码值作为 skos:Concept。
  • SHACL：18,459 个三元组的 NodeShape/PropertyShape，按类约束数据类型、长度、模式、关联目标类，并对数据元素设置 sh:maxCount 1。
  • PROV-O / DCAT 3 / VoID：来源、构建活动、校验和与数据集目录。

示例 SPARQL

PREFIX wco: <https://w3id.org/wco-dm/4.3.0#>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

# 1. 某类的数据属性
SELECT ?p ?label ?range WHERE {
  ?p a owl:DatatypeProperty ;
     rdfs:domain ?d ;
     rdfs:range ?range ;
     rdfs:label ?label .
  FILTER(?d = wco:C_42A)
}

# 2. 包含 GoodsShipment 的父类
SELECT ?parent WHERE {
  ?parent wco:hasGoodsShipment wco:C_67A .
}

由于域为并集类表达式，简单三元组查询不会直接给出全部域成员；可结合 wco:usedByClass 注解查询。

包配置剖面（Profile Layer）

核心本体回答“WCO DM 类/属性是什么”；profile 层回答“某个包如何使用它”。4 个包被建模为 prof:PackageProfile，包内类被建模为核心类的 OWL 子类（如 prof:P_BIP_DEC_C_42A rdfs:subClassOf wco:C_42A），包内数据元素被建模为 prof:ProfileProperty 个体。

profile 图：25,407 个三元组、387 个 profile 类、1,541 个数据元素、1,077 个关联、37 个使用标记；profile SHACL 形状 14,248 个三元组。合规样例通过，重复 dp_D014 的违规样例按 Max=1 失败。

文件：profiles.ttl · profiles-shapes.ttl · profile-layer.md

建模约定与限制

  • 把 LIB 的全局属性建模为全局属性：数据元素按 Attr. ID 合并，关联角色按角色名合并；域使用 owl:unionOf 表示多个使用类。
  • 类之间不是 rdfs:subClassOf 的语义分类，而是 OIS 的包含/组合关系；因此用对象属性而非子类公理表达层次。
  • 基数来自 4 个包级数据模型 sheet：8,212 个数据元素行全部为 Min=0、Max=1，已写入 wco:minOccurs / wco:maxOccurs 与 SHACL sh:maxCount 1。对象角色的最大值随包变化，因此不写全局 max。
  • 代码表只收录 LIB 明确列出的代码值；没有描述时不编造含义。UN/EDIFACT、ISO 等外部代码表仅保留来源说明。
  • WCO 的日期时间在 XML 中使用 CCTS DateTimeString + formatCode；本体为语义查询方便统一映射为 xsd:dateTime，同时保留原始 wco:format。
